# 🇧🇷 Português

## 📋 Sobre o Projeto

Projeto desenvolvido como desafio do **Módulo 5** do curso Full Stack Pro - Sujeito Programador. Consiste em duas páginas de autenticação — **Login** e **Cadastro** — com layout dividido em duas colunas, design limpo e responsivo.

## 🖥️ Páginas

| Página | Descrição |
|--------|-----------|
| `index.html` | Página de **Login** com campos de e-mail e senha |
| `pages/signup.html` | Página de **Cadastro** com campos de nome, e-mail, senha e aceite de termos |

## 🚀 Tecnologias Utilizadas

- **HTML5** — Estrutura semântica
- **CSS3** — Estilização com variáveis CSS, Flexbox e Media Queries
- **Google Fonts** — Tipografia com a fonte [Roboto](https://fonts.google.com/specimen/Roboto)

## ✨ Funcionalidades & Destaques

- ✅ Layout responsivo (mobile e desktop)
- ✅ CSS Custom Properties (variáveis de cor)
- ✅ Tipografia fluida com `clamp()`
- ✅ Efeitos de hover em links e botões
- ✅ Navegação entre as páginas de Login e Cadastro
- ✅ Pseudo-elemento decorativo (`::after`) no botão de submit

# 🇺🇸 English

## 📋 About the Project

Project built as a challenge for **Module 5** of the Full Stack Pro course - Sujeito Programador. It consists of two authentication pages — **Login** and **Sign Up** — featuring a split two-column layout with a clean, responsive design.

## 🖥️ Pages

| Page | Description |
|------|-------------|
| `index.html` | **Login** page with email and password fields |
| `pages/signup.html` | **Sign Up** page with name, email, password, and terms agreement fields |

## 🚀 Technologies Used

- **HTML5** — Semantic structure
- **CSS3** — Styling with CSS variables, Flexbox, and Media Queries
- **Google Fonts** — Typography using [Roboto](https://fonts.google.com/specimen/Roboto)

## ✨ Features & Highlights

- ✅ Responsive layout (mobile & desktop)
- ✅ CSS Custom Properties (color variables)
- ✅ Fluid typography with `clamp()`
- ✅ Hover effects on links and buttons
- ✅ Navigation between Login and Sign Up pages
- ✅ Decorative pseudo-element (`::after`) on the submit button
